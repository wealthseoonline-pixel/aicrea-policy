# AICrea legal pages

The canonical public pages are served by the AICrea Supabase legal-pages endpoint so the Android app and store listing use stable, live URLs.

- Home: https://zbljasysemagszenljag.supabase.co/functions/v1/aicrea-legal/
- Privacy Policy: https://zbljasysemagszenljag.supabase.co/functions/v1/aicrea-legal/privacy.html
- Terms of Service: https://zbljasysemagszenljag.supabase.co/functions/v1/aicrea-legal/terms.html
- Refund & Cancellation: https://zbljasysemagszenljag.supabase.co/functions/v1/aicrea-legal/refund.html
- Account & Data Deletion: https://zbljasysemagszenljag.supabase.co/functions/v1/aicrea-legal/delete-account.html

The HTML files in this repository are the editable source copies. When changing a policy, update the corresponding HTML file here and redeploy the matching page content in `supabase/functions/aicrea-legal/index.ts` in the AICrea app repository.
